# PocketSDR Desktop 打包说明（P4）

## 产物

| 项目 | 值 |
|---|---|
| 产物路径 | `dist/pocket-desktop/`（`pocket-desktop.exe` + `_internal/`） |
| 体积 | 约 180 MB |
| 入口 | 仓库根 `pyi_entry_pocket.py` → `pocket_desktop.app.main` |
| spec | 仓库根 `pocket_desktop.spec`（onedir / console=False / no UPX） |
| 构建耗时 | 约 1 分钟（增量，i9-12900H） |

随包内容（`_internal/` 下）：

- `engine/`：三引擎变体 `pocket_web_local.exe`（原版 BRDC/SAAS）、`pocket_web_both_off.exe`（匹配版 大气OFF）、`pocket_web_iflc.exe`（IFLC 双频）——来自 `../PocketSDR/local_build/`（免 Soapy 源码级构建）
- `engine/html/`：引擎自带 Web 资源（`-web` 模式内部使用，浏览器不出现）
- `pocket_desktop/assets/world_land.geojson`：定位页地图底图

## 构建命令

```bash
# 前置：源码态自测通过
.venv/Scripts/python.exe -m pocket_desktop.app --selftest out/<runid>/gpssim.bin

# 打包（若 dist/pocket-desktop 已存在，PyInstaller 会先清旧目录——
# 沙箱下批量删除会被安全策略拦截，需带权限执行 rm -rf dist/pocket-desktop 后重建）
.venv/Scripts/pyinstaller.exe pocket_desktop.spec --noconfirm \
    --distpath dist --workpath .workbuddy/pyi_build_pocket
```

## frozen 资源定位（PyInstaller 6.x onedir 要点）

PyInstaller 6.x 的 onedir 布局把除主 exe 外的全部文件放在 `_internal/`，
`sys._MEIPASS` 指向该目录。三处定位逻辑已按此适配：

1. `core/engine_mgr.py`：`_pkg_root()` = `sys._MEIPASS`（兜底 exe 旁）；`engine_dir()`/`html_dir()` frozen 依次探测 `_MEIPASS/engine` 与 exe 旁 `engine/`。
2. `ui/widgets.py` MapWidget：geojson 找不到源码路径时改探 `_MEIPASS/pocket_desktop/assets/`。
3. `ui/pages/console.py` 真值联动 / `app.py` selftest 缺省 IQ：frozen 时依次搜 exe 旁 `out/`、exe 上三级 `out/`（dist 在仓库内时可命中仓库 out）、cwd `out/`。

运行时数据目录（与资源分开，均落 exe 旁）：`runlog/`（引擎日志）、`~/.pocket-desktop.json`（参数持久化）。

## 与源码态差异

- 源码态引擎取 `../PocketSDR/local_build/`（可用 `POCKETSDR_BUILD` 环境变量覆盖）；frozen 态取包内 `engine/`，两态行为一致。
- 打包版双击即用，无需 Python 环境与 PocketSDR 目录在场。
