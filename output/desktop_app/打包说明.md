# gnss-sim 桌面版打包说明（M4）

## 一键构建

```bash
# 仓库根目录（需 .venv 已装 PySide6/pyqtgraph/pyinstaller）
.venv/Scripts/python.exe -m PyInstaller -y gnss-sim-desktop.spec
# 产物
dist/gnss-sim/gnss-sim.exe        # onedir，整目录可拷贝分发
```

## 打包要点（spec 已处理）

| 事项 | 处理 |
|---|---|
| 惰性导入的后端 | `collect_submodules("backend"/"desktop")` 强制收集（bridge 函数内 `import backend.app` 静态分析追不到） |
| native 引擎 | `backend/synth/native/libgnsssynth.dll` → `_internal/backend/synth/native/`（ABI v30） |
| Web 兼容层 | `frontend/` 整目录入包（backend.app 末尾 StaticFiles mount 需要目录存在） |
| 离线地图 | `desktop/assets/world_land.geojson`（Natural Earth 110m land） |
| 三方数据 | `collect_data_files(georinex / xarray / pyqtgraph)` |
| 体积裁剪 | excludes：matplotlib、tkinter、QtWebEngine/Qml/Quick3D/Multimedia 等 |
| 输出目录 | frozen 下 `out/ data/ logs/` 自动落 **exe 旁**（`desktop/app.py::_apply_frozen_dirs`，环境变量可覆盖） |
| 硬件面 | 恒 `ALLOW_TX=0`（桌面版无发射链） |

## 发版验收清单

1. 干净目录双击 `gnss-sim.exe` → 六页可切换、中文正常；
2. 命令行冒烟：`gnss-sim.exe --selftest` → 输出 `SELFTEST-PASS`（preview→generate→receiver 全链路，产物在 exe 旁 `out/`）；
3. GUI 全流程：新建任务 → Preview（Skyplot/星表）→ Generate（进度条）→ 自动 Verify Fix（KPI+跟踪解+误差曲线）→ 图谱页四联图；
4. 场景库：保存场景后重启 exe 可载入；历史页可见旧 run；
5. 设置对话框：native 引擎行显示"已就位 ✓"。

## 已知边界

- onedir 首启解压/加载 ~5-10 s（含 numpy/xarray/georinex 导入）；onefile 更慢，暂不做；
- `precise(SP3)` 与 PPK 类遗留端点契约仍在 backend，桌面 UI 提供 sp3_path 输入（功能可用，非本轮重点）；
- 杀毒软件可能误报未签名 exe：正式分发前补代码签名（占位）。
